**爬虫说明** `finance_crawler.py`
- 数据源：腾讯财经 `qt.gtimg.cn`（东方财富接口在当前网络被拒，Sina 返回 403，腾讯可用）
- 仅用 Python 标准库（`urllib`/`csv`/`json`），无需装第三方依赖
- 抓取脚本顶部 `CODES` 列表里的 55 个股票/指数（上证、深证、创业板、沪深300 等指数 + 招商银行、贵州茅台、宁德时代、比亚迪等个股），分批请求
- 字段：最新价、涨跌额、涨跌幅、今开/昨收/最高/最低、成交量、成交额、换手率、市盈率、市净率、振幅、量比、时间
- 带 3 次重试；结果同时输出 **CSV（utf-8-sig，Excel 可直接打开）** 和 **JSON**，按时间戳命名存到 `data/`

两点提示：
1. 本次环境 shell 是 Windows `cmd`（不支持 heredoc），我改用 `python -c` 写文件绕过了限制；如果你所在环境是 bash，直接编辑运行即可，程序本身无平台依赖。
2. 想抓别的标的，改 `CODES` 即可（指数如 `sh000001`，个股如 `sh600000`/`sz000001`）。
